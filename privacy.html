Política de privacidad

Última actualización: 18 de octubre de 2026.

Qué hace la aplicación

«¿Qué Salió Mal?» es una herramienta de uso personal del propietario del canal. Usa la API de YouTube para subir videos, y editar sus títulos, descripciones y etiquetas, en el canal del propietario.

Datos que se acceden

Solo se accede a la cuenta de YouTube del propietario y únicamente a lo necesario para subir y administrar sus propios videos. No se acceden datos de otros usuarios.

Almacenamiento y uso

El token de autorización se guarda de forma privada en el equipo del propietario. No se vende, comparte ni transfiere a terceros ningún dato, ni se usa para publicidad.

Cumplimiento

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios API de Google, incluidos los requisitos de uso limitado. También se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Revocar el acceso

El propietario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions.
